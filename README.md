# 📅 Golendar

**Golendar** は、シンプルで使いやすい月・週・日表示を備えた Android カレンダーアプリです。  
プライバシーに配慮した「ローカル専用モード」と、利便性の高い「Googleカレンダー同期モード」の2つを搭載し、用途に合わせて切り替えて使用できます。

## ✨ 主な機能

### デュアルエンジン搭載

- **Golendarモード**：デバイス内部（ローカル）でのみ予定を管理。外部サーバーと通信しないため、完全にプライベートな予定の管理に最適です。
- **Googleモード**：Googleカレンダーと同期し、他のデバイスやサービスと予定を共有できます。

### 柔軟なカレンダービュー

- 月間・週間・日間の3つのビューをシームレスに切り替え可能。
- **月表示の下部リスト表示切替**  
  ヘッダー左のトグルで、月グリッド下の予定リストを ON/OFF できます。OFF にすると月グリッドが画面いっぱいに拡大し、予定を俯瞰しやすくなります。設定はアプリを再起動しても保持されます。
- **日付タップでその日の予定をポップアップ表示**  
  月表示で下部リストを OFF にしているとき、日付をタップするとその日の予定がポップアップで表示されます。ポップアップから予定の追加・詳細確認が可能です。
- **「今日」ボタンで今日の月表示へ**  
  どの表示からでも、ヘッダーのカレンダーアイコンをタップすると今日の月表示へジャンプします。
- 上下スワイプで前後の期間へ移動（月・週・日すべてで「同方向に素早く2回」で発火）。
- 左右スワイプで日・週・月のタブを切り替え。
- 期間切替時は上下スライドアニメーションで滑らかに遷移。
- スワイプ操作は月・週・日すべてで統一されており、どの画面でも同じ操作感で使えます。

### 繰り返し予定

- 繰り返し予定（毎日 / 平日 / 毎週 / 毎月 / 毎年）の表示・編集に対応。
- 繰り返しの終了日を指定可能（未指定なら無期限）。
- カレンダーの日付セルから追加した場合は日付がロックされ、繰り返しONで終了日が開始日に自動で揃います。

### 予定の簡単共有

- 予定詳細ダイアログから、タイトル・日時・場所・メモをテキストとして他アプリ（LINE、メール等）へ共有できます。

### アプリショートカット対応

- ホーム画面のアイコン長押しから「予定追加」「今日」「検索」を素早く起動できます。
- ライト/ダークモードそれぞれに最適化されたアイコンを表示します。

### カスタマイズ可能なホーム画面ウィジェット

- 日間・週間・月間の3種類を提供。
- アプリ内の設定と連動し、16色のパステルカラーで背景を自由にカスタマイズ可能。

### 正確なリマインダー通知

- 「定刻（開始時間）」および「10分前」の通知をサポート。
- AndroidのDoze（省電力機能）対策として `AlarmManager` の正確なアラーム機能を使用し、端末再起動時にも自動で再スケジュールします。

### 初回起動時のセットアップ

- 初回起動時に、通知の許可・正確なアラーム・バッテリー最適化の無効化を順番に案内するダイアログが表示されます。
- 続けて Google カレンダーへのアクセス許可を案内します。
- すべてのステップは「あとで」でスキップでき、後から設定画面で変更可能です。

### 強力なデータバックアップ＆復元

- ローカル予定とアプリ設定（テーマ・曜日の色・週の始まりなど）を JSON ファイルとしてエクスポート可能。
- Googleカレンダーの予定をバックアップし、Golendarモードや別のアカウントへ「追記」することで、予定の移行・統合が簡単に行えます。

### 日本の祝日・文化イベントの自動識別

- 外部APIから日本の祝日を自動取得し、カレンダーに表示。
- 祝日・文化イベント（七夕・バレンタインなど）・誕生日を自動判別し、それぞれ異なる色で表示します。

## 🎨 カスタマイズとデザイン

- **表示テーマ**：ライトモード / ダークモード / システム追従
- **アプリ背景色**：16種類のパステルカラーから選択。カレンダー・設定画面・ウィジェットすべてに連動し、背景の明るさに応じて文字色も自動調整
- **曜日の色付け**：すべての曜日に自由にカラーを設定可能
- **イベントの色分け表示**：誕生日はオレンジ、文化イベントは緑、通常予定はテーマカラーで自動判別
- **週の始まり**：日曜日 / 月曜日 を選択可能

## ⚠️ 既知の仕様・注意点

- **カレンダー権限について**  
  Googleカレンダーモードを利用するには、端末の設定からカレンダーへのアクセス権限（`READ_CALENDAR` / `WRITE_CALENDAR`）を許可する必要があります。  
  権限が付与されていない状態でGoogleモードを選択しようとすると、説明ダイアログが表示され、許可した場合は再起動を促すモーダルが表示されます。拒否した場合は自動的にGolendarモードに切り替わります。  
  また、初回起動時にも同様のダイアログが表示され、後から設定画面で変更することも可能です。

- **通知機能について**  
  確実な通知を受け取るために、**アプリの通知許可**を有効にし、設定画面から「バッテリー最適化の無効化」および「正確なアラーム機能の許可」を行ってください。  
  一部のメーカー（Xiaomi, OPPO 等）の端末では、OS独自のタスクキルにより通知が遅延する場合があります。

- **繰り返し予定について**  
  繰り返し予定の「終了」フィールドは、1回分の所要時間を指定する項目です。繰り返し全体の終了日は「繰り返しの終了日を指定」で別途設定してください。  
  また、カレンダーの日付セルから追加した場合は、日付の変更がロックされ、繰り返しONで終了日が開始日に自動で揃います（FABからの追加・既存予定の編集では自由に変更可能）。

- **祝日データについて**  
  日本の祝日データは `holidays-jp.github.io` から取得しています。そのため、インターネット接続が必要です（初回起動時および30日ごとに自動更新されます）。オフライン時は最後に取得したデータを表示します。

- **復元機能について**  
  データの誤消失を防ぐため、Googleモード選択時は JSON ファイルからの「復元（上書き）」がブロックされ、「追記」のみが許可される安全設計となっています。
