# 📅 Golendar

월간・주간・일간 표시를 갖춘 Android 캘린더 앱.
프라이버시를 중시하는 **Golendar 모드**(앱 내 완결・여러 로컬 캘린더 지원)와 **Google 모드**(Google 캘린더 동기화) 두 가지를 탑재.

---

## 📲 다운로드

최신 APK는 [GitHub Releases](https://github.com/monsivamon/Golendar/releases/latest) 에서 받을 수 있습니다.
APK를 기기에서 열고, '알 수 없는 앱 설치'를 허용한 후 설치하세요.

## ✨ 주요 기능

### 듀얼 엔진
- **Golendar 모드**: 외부 동기화 없음. 앱 내에서만 완결됩니다(공휴일 가져오기・지도 표시에만 네트워크 사용). 여러 개의 로컬 캘린더를 만들고 관리할 수 있습니다.
- **Google 모드**: Google 캘린더와 동기화.

### Golendar 모드의 멀티 캘린더 지원
- 앱 내에 여러 개의 로컬 캘린더를 만들고 일정을 나누어 관리할 수 있습니다.
- 첫 실행 시 '내 캘린더'를 자동 생성합니다. 내 캘린더는 삭제할 수 없지만, 숨길 수는 있습니다.
- 캘린더마다 이름・색상・표시 ON/OFF・정렬 순서를 설정할 수 있습니다.
- 기본 캘린더 이외의 캘린더를 삭제하면, 속한 일정도 함께 삭제됩니다(삭제 전에 건수를 확인하는 대화상자를 표시).
- 일정 편집 화면에서 추가할 캘린더를 선택할 수 있습니다(표시 중인 캘린더가 2개 이상일 때).
- '모두 표시'로 일괄 ON 전환 가능(숨김 0개는 불가).
- 표시 캘린더가 2개 이상일 때, 일정 카드에 캘린더 이름과 색상을 표시.

### Google 캘린더의 멀티 캘린더 지원
- 계정 단위로 캘린더를 목록 표시하고, 표시할 항목을 선택합니다.
- 설정 화면에서 개별적으로 표시 ON/OFF, 색상 사용자 지정이 가능합니다.
- 표시 캘린더가 2개 이상일 때, 일정 카드에 캘린더 이름과 색상을 표시.
- '캘린더 목록 다시 가져오기'로 추가・삭제에 대응합니다.

### 캘린더 뷰
- 월간・주간・일간 뷰를 매끄럽게 전환.
- 월 그리드 아래의 일정 목록은 ON/OFF 전환 가능(하단 목록 OFF 시 날짜 탭으로 팝업 표시).
- 월 그리드의 일정 바는 3건까지 표시하고, 초과분은 '+N'으로 표시합니다(하단 목록 OFF 시 6건까지). 하단 목록 표시 중에는 표시되지 않은 항목이 있다는 인지를 표시합니다.
- 일정 검색(과거 2년 ~ 미래 2년, 공휴일・문화・생일은 제외).
- 위아래 스와이프로 앞뒤 기간, 좌우 스와이프로 일・주・월 탭 전환.
- 일정 카드에 종류 이모지 표시(🎂 생일 / 🎌 문화 / 🗾 공휴일).

### 지도로 장소 선택
- MapLibre Native + OpenFreeMap 지도에서 선택.
- 현재 위치 추적 버튼 포함. 'POI 이름, 주소' 형식으로 저장.

### 반복 일정
- 매일 / 평일 / 매주 / 매월 / 매년. 종료일 지정 가능.

### 일정 공유
- 상세 대화상자에서 텍스트로 다른 앱에 공유.

### 사진 첨부(Golendar 모드 전용)
- 일정에 최대 5장 첨부. 긴 변 1920px로 자동 축소.
- 확대 뷰어 및 기기의 'Pictures/Golendar' 폴더로 내보내기 지원.

### AI 분석을 통한 일정 일괄 등록(BETA・Golendar 모드 전용)
- 캘린더 이미지를 외부 AI로 읽어 들이고, 반환된 JSON으로부터 일정을 일괄 등록합니다.
- 프롬프트 복사／공유 시트 지원. 미리보기에서 선택하여 등록.

### 앱 바로가기
- 아이콘 길게 누르면 '일정 추가', '오늘', '검색' 표시.

### 홈 화면 위젯
- 일간・주간・월간 3종류. 앱 설정(테마・배경색・표시 캘린더・공휴일 표시)과 연동.
- 월간 위젯은 앞뒤 달 셀까지 포함하여 일정 점을 표시.
- Golendar 모드에서는 표시 중인 로컬 캘린더, Google 모드에서는 표시 중인 Google 캘린더의 일정을 반영.

### 리마인더 알림
- 정각・10분 전 알림. `AlarmManager`의 정확한 알람으로 Doze 대응.
- 공휴일・문화 행사는 알림 대상에서 제외. **생일은 알림 대상입니다**(천황 생일은 공휴일로 처리되어 제외).
- 표시 캘린더 설정과 연동(Golendar/Google 양쪽 모드의 표시 캘린더가 대상).

### 첫 실행 시 설정
0. Welcome 화면(첫 실행 시, 그리고 버전 업데이트 시에 표시)
1. 알림 권한 허용(알림 → 정확한 알람 → 배터리 최적화 비활성화)
2. Google 캘린더 접근 권한
3. 표시할 캘린더 선택(Google 모드일 때)
4. 제스처 조작 안내

위치 정보는 지도를 처음 열 때 안내됩니다.

### 백업 및 복원
- **표시 중인 캘린더의 일정을 한꺼번에 내보냅니다**(Golendar/Google 양쪽 모드).
- '사진도 백업' ON 시는 ZIP(Golendar 모드만). OFF 시는 JSON.
- 백업 파일에는 '원본 캘린더 정보'가 포함되어 있어, 복원 시 캘린더별로 나누어 복원할 수 있습니다.
- 여러 캘린더 표시 중에 '저장'을 누르면, 대상 목록을 확인하는 대화상자를 표시합니다.
- 파일 이름에 날짜를 부여(예: `golendar_backup_YYMMDD.json`).
- **복원 전 미리보기**: 파일 선택 후 포함된 캘린더 수・일정 수・사진 수를 확인할 수 있습니다.
- **복원할 원본 캘린더 선택**: 체크박스로 여러 개 선택할 수 있습니다(구 형식 백업에서는 자동으로 숨겨짐).
- **복원 대상 지정**:
  - Google 모드: 복원 대상 캘린더를 1개 선택.
  - Golendar 모드: '같은 이름의 캘린더를 자동 생성하여 나누기' 또는 '특정 로컬 캘린더로 모으기'를 선택.
- **같은 이름 캘린더 덮어쓰기 확인**: Golendar 모드에서 같은 이름의 캘린더가 이미 존재하는 경우, 덮어쓸지 확인하는 대화상자를 표시합니다.
- **추가 시 중복 건너뛰기**: 제목・시작・종료・종일 플래그가 일치하는 일정은 중복 등록하지 않습니다.
- **구 형식(v1.1.6 이전) 백업 호환**: 추가는 Google/Golendar 모두 가능(추가할 캘린더를 선택). 복원(덮어쓰기)은 Golendar 모드만 가능하며, 내 캘린더로 복원됩니다. 구 형식 ZIP의 Google 모드 추가는 불가.
- Google 모드에서는 '복원(덮어쓰기)' 불가, '추가'만 가능.
- 공휴일 데이터는 포함되지 않으며, 복원 시 자동으로 다시 가져옵니다.

### 공휴일・문화 행사
- `holidays-jp` API에서 자동으로 가져옵니다(최초 1회 + 30일마다).
- 공휴일・문화・생일을 자동으로 판별하고, 색상과 이모지로 표시합니다.
- 설정 화면에서 '공휴일 표시' ON/OFF 전환 가능.
- 공휴일은 캘린더 표시 ON/OFF와 관계없이 항상 표시 대상입니다.

### 튜토리얼
- 설정 화면의 '튜토리얼'에서 언제든지 13종류 이상의 안내를 다시 볼 수 있습니다.
- 내용: 캘린더 접근 권한 / 제스처 조작 / 지도 사용법 / AI 분석 / 캘린더 표시 및 색상 설정 / 월간 표시의 하단 목록 / 일정 추가 / 일정 편집 및 삭제 / 반복 일정 / 사진 활용 / 검색 사용법 / 알림 설정 / 백업 및 복원 / 위젯과 바로가기
- '캘린더 모드' 섹션을 처음 펼칠 때는, Golendar/Google의 차이와 캘린더 목록 조작 방법을 자동으로 표시합니다.
- 각 튜토리얼은 그림 설명이 포함된 여러 페이지 구성으로, 놓치기 쉬운 함정(반복의 종료일, 이 날짜만 삭제의 분할 동작, 추가와 복원의 차이, 숨긴 캘린더의 영향 등)도 친절하게 설명합니다.

## 🎨 사용자 지정

- 테마: 라이트 / 다크 / 시스템 설정 따름
- 언어: 일본어 / English / 简体中文 / 한국어(설정 화면의 '표시 언어' 섹션에서 전환. 전환 후에도 설정 화면에 머무릅니다. 미선택 시 기기 언어에서 자동으로 판별됩니다)
- 앱 배경색: 16색의 파스텔 색상(캘린더・설정・위젯 연동)
- 요일 색상: 모든 요일에 설정 가능
- 캘린더별 색상: **Golendar 모드・Google 모드 모두** 개별 설정 가능. 테마에 따라 자동 할당(라이트=진한색 16색 / 다크=밝은색 16색).
- 이벤트 색상 구분: 생일=주황, 문화=초록, 일반=테마 색상(캘린더 색상 우선)
- 주 시작 요일: 일요일 / 월요일
- 공휴일 표시: ON/OFF

## ⚠️ 주의 사항

- **캘린더 권한**: Google 모드에서는 `READ_CALENDAR` / `WRITE_CALENDAR`가 필요합니다. 거부 시 자동으로 Golendar 모드로 전환됩니다. Google 계정이 없는 경우 전환 시 안내가 표시됩니다. 영구적으로 거부된 경우 설정 화면으로 유도하는 대화상자를 표시합니다.
- **표시 캘린더**: **최소 1개의 캘린더를 표시해야 합니다**(0개는 불가). Golendar 모드에서는 내 캘린더가 삭제 불가이므로, 항상 1개 이상 남아 있습니다. Google 모드에서 캘린더를 추가・삭제한 후에는 '캘린더 목록 다시 가져오기'를 실행하세요.
- **로컬 캘린더 삭제**: 기본(내 캘린더) 이외의 로컬 캘린더를 삭제하면, 속한 일정도 함께 삭제됩니다. 삭제 전에 건수를 확인하는 대화상자가 표시됩니다.
- **Google 모드 전환**: v1.1.7에서는, 권한이 이미 허용되어 있다면 앱 재시작 없이 즉시 전환됩니다.
- **알림**: 배터리 최적화 비활성화와 정확한 알람 허용을 권장합니다. 일부 제조사 기기에서는 지연이 있습니다.
- **지도**: 네트워크 연결 필요. 위치 정보를 거부해도 지도 기능은 사용할 수 있습니다.
- **검색**: 공휴일・문화・생일은 제외됩니다.
- **반복**: '종료'는 1회분의 소요 시간입니다. 전체 종료일은 별도로 지정합니다.
- **공휴일 데이터**: 오프라인 시 마지막으로 가져온 데이터를 표시합니다.
- **백업**: Google 모드에서는 '복원(덮어쓰기)' 불가, '추가'만 가능. 복원 대상 캘린더는 쓰기 가능한 캘린더에서 선택합니다.
- **구 형식 백업**: v1.1.6 이전의 백업은, 추가라면 Google/Golendar 모두 가능합니다(추가할 캘린더를 선택). 복원(덮어쓰기)은 Golendar 모드만 가능합니다(내 캘린더로 복원). 구 형식 ZIP을 Google 모드에서 추가하는 경우, 미리 Golendar 모드로 전환하세요.
- **사진 첨부**: Golendar 모드 전용. 클라우드 자동 백업에서는 제외됩니다.
- **AI 분석**: Golendar 모드 전용. 분석 결과는 로컬 DB에만 반영됩니다.
